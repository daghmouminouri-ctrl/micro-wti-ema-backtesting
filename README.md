# Micro WTI Futures: Backtesting an EMA Crossover Strategy

A practical project exploring how a simple trading idea can be
translated into rules, implemented in Pine Script, and evaluated
using historical data.

## Project overview

- Market: Micro WTI crude oil futures (NYMEX:MCL1!)
- Timeframe: 2-hour candles
- Baseline: Long-only 20/50 EMA crossover
- Modification: 200-period EMA trend filter
- Trading assumptions: One contract, commissions, and simulated slippage

The report compares the baseline and filtered strategies and
discusses results from a separate evaluation period.

## Report

[Read the report](Micro_WTI_EMA_Backtesting.pdf)

## Main takeaway

The project evaluates performance beyond net profit, including
drawdown, expectancy, and the influence of individual trades.

## Limitations

Historical coverage differs between some tests, and the separate
evaluation period contains only 20 completed trades. The results
do not establish a robust trading edge.
